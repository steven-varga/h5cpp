@page reports_inventories Inventories & guides

Exhaustive catalogues of what h5cpp exposes, plus the controlled vocabulary that holds the docs together.

## Members

- @subpage aliases_reference — the Doxygen alias vocabulary (this is the canonical reference for what each `\par_*` / `\tpar_*` / `\returns_*` / `\sa_*` / `\func_*` token expands to)
- @subpage reports_handle_inventory — every `h5::hid_t<T>` handle: `fd_t`, `ds_t`, `gr_t`, `at_t`, `dcpl_t`, `fapl_t`, etc.
- @subpage reports_filters_inventory — the filter pipeline: gzip, zstd, libdeflate, lz4, szip, Gorilla, shuffle, fletcher32, scaleoffset, nbit
- @subpage reports_stl_pretty_print_guide — the `h5::cout` pretty-print machinery for STL containers
- @subpage reports_hdf5_112_feature_report — coverage matrix of HDF5 1.12 features and where they land in h5cpp
