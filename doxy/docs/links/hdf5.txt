## The previous implementation here used markdown reference-style links
## ([name][] + [name]: URL on separate lines) joined by \n. Doxygen
## substitutes \n as <br/> rather than a true newline, so the markdown
## parser couldn't pair references with their definitions and the @sa
## block rendered as literal "[name][]" text plus the URL definitions as
## visible lines. Rewritten to use inline markdown links ([name](url))
## so no reference resolution is needed — Doxygen renders the labels as
## proper hyperlinks unconditionally.
##
