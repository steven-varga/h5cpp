Detailed Description

template<typename T>
struct h5::has_scatter< T >

Compile-time trait to determine if a type uses scatter/gather I/O.

The h5cpp-compiler emits specializations of h5::scatter<T> and h5::gather<T> for user-defined structs with heap-indirection fields (std::vector, std::string, etc.). The H5CPP_REGISTER_SCATTER(T) macro sets this trait to true_type.
